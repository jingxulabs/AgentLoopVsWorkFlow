Headline

The decision metric is cost per correct answer, not accuracy. An architecture that buys a few points of EM for several times the tokens is a different call at 100 questions/day than at 10 million.

Performance by architecture

One row per option, rolled up across every condition (each carries equal n, so conditions are weighted equally). tail is p95 ÷ mean tokens — how far the expensive runs sit from the typical one. cost CV is the coefficient of variation: lower means more forecastable. s/call is median per-call latency, which is the latency figure that isn't swamped by gateway tail.

Cost–accuracy frontier

How runs ended

Failure modes are not symmetric. A loop can fail to terminate; a DAG cannot. A DAG can only fail by answering confidently from bad context.

Head-to-head on identical questions

Every arm saw the same questions, so they can be compared pair by pair rather than mean against mean. Two arms can post the same accuracy while disagreeing on half the questions — that means different competencies, not equivalent ones, and an average erases it. Bars show only the questions where the two arms disagreed; p is an exact McNemar test on those discordant pairs.

Accuracy by question type

A fixed 2-hop graph is a bet that every question bridges through an intermediate entity. comparison questions don't — they need two independent lookups — so this is where a fixed shape should cost accuracy outright.
